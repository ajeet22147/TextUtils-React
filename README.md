# 📄 TextUtils React A simple and responsive React web app for text operations like UPPERCASE, lowercase conversion, remove extra spaces, copy to clipboard, word/character count, reading time, light/dark mode, and responsive UI. 
<br/>
## Technologies Used: 
<br/>
React.js, JavaScript (ES6+), HTML5, CSS3, Bootstrap, Git & GitHub.
<br/>
## Installation git clone https://github.com/ajeet22147/TextUtils-React.git cd TextUtils-React npm install npm start ## Future Improvements Text-to-speech, download text as file, multiple theme colors.
